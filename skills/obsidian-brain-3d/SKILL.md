# 옵시디언 노트를 3D 뇌로 보기 (obsidian-brain-3d)

노트 보관함을 읽기만 해서 `data.js` 한 파일을 만들고, 그 데이터를 엑스레이 뇌와 두개골 안에 점으로 뿌려 보여 주는 뷰어입니다. 노트는 그룹(폴더, 문서 종류, 태그 가운데 하나)에 따라 뇌의 여섯 영역에 나뉘어 놓이고, `T` 키를 누르면 같은 점들이 세계수의 잎으로 옮겨 갑니다. `A` 키를 누르면 세 번째 탭 「AI 엔진」이 열려, `config.js`에 적은 도구들이 빛줄기로 가운데 뇌에 연결되고 도구마다 제목에 그 이름이 들어간 노트 수가 나옵니다. 화면의 수학 도형은 분위기를 위한 장식이고, 아래 여섯 칸에는 실제 노트 제목과 날짜, 연결 수가 그대로 나옵니다.

## 언제 쓰나요
- 옵시디언 보관함이나 마크다운 노트 폴더가 어떤 분야로 얼마나 쌓였는지, 무엇이 무엇과 이어져 있는지 한눈에 보고 싶을 때
- 강의나 영상에서 "내 두 번째 뇌"를 보여 줄 화면이 필요할 때
- 최근에 노트가 많이 늘어난 분야를 확인하고 싶을 때

## 준비물: 옵시디언이나 LLM 위키가 꼭 있어야 하나요?
아닙니다. 필요한 것은 **`.md` 파일이 들어 있는 폴더 하나**와 Node 18 이상, 그리고 웹 브라우저뿐입니다. 옵시디언 앱을 설치하지 않아도 되고, AI가 관리하는 LLM 위키가 없어도 됩니다. 다만 노트에 아래 요소가 많을수록 화면이 풍성해집니다.

| 노트에 있으면 | 화면에서 좋아지는 것 | 없으면 |
|---|---|---|
| 노트 30개 이상 | 뇌와 나무가 점으로 채워집니다 | 점이 듬성듬성하게 보입니다 |
| `[[다른 노트]]` 링크 | 노트끼리 빛의 선으로 이어지고 LINKED·CHORD 칸이 살아납니다 | 선 없이 점만 보입니다 |
| 폴더, 머리말 `type`, 또는 태그 | 뇌의 여섯 영역과 나무의 뿌리·줄기·가지로 나뉩니다 | 한 영역에 몰립니다 |
| 머리말 `created`(만든 날) | 최근 노트 목록과 일별 그래프가 정확해집니다 | 파일 시각을 대신 씁니다 |
| 머리말 `status`(예: verified) | 확인된 노트가 더 크게 빛납니다 | 모두 같은 크기입니다 |

머리말 예시입니다.
```markdown
---
type: 교훈
status: verified
created: 2026-10-20
tags: [youtube, upload]
---
예약 공개 영상은 공개 뒤에 고정 댓글을 단다. 관련: [[유튜브 업로드 점검표]]
```

**작성자와 같은 화면을 원한다면**: 작성자의 보관함은 [obsidian-llm-wiki](https://github.com/reedodev/obsidian-llm-wiki) 구조(받은자료·원본·위키 폴더, 머리말 type·status·created, 서로 이어진 위키 문서)로 운영합니다. 이 구조로 만든 보관함은 머리말 type으로 영역이 나뉘고 연결이 많아서 화면이 가장 풍성하게 나옵니다. 새로 시작한다면 그 스킬로 저장고를 먼저 만들고 이 스킬로 그리는 순서를 권합니다.

## 노트가 아직 적다면 (LLM 위키처럼 키우기)
이 스킬은 노트를 읽기만 하고 만들지는 않습니다. 노트가 적다면 먼저 에이전트에게 이렇게 요청해 보관함을 키운 뒤 그림을 다시 만들면 됩니다.
- "오늘 한 작업에서 배운 것을 `MyVault/교훈` 폴더에 노트 하나씩 정리해 줘. 노트마다 type, status, created 머리말을 넣고, 관련 있는 기존 노트를 `[[ ]]` 링크로 이어 줘."
- "이 폴더의 노트들을 읽고 서로 관련 있는 것끼리 `관련:` 줄에 `[[ ]]` 링크를 달아 줘. 본문 내용은 바꾸지 마."
- "머리말이 없는 노트에 파일 날짜를 보고 created를 채워 줘. 확실하지 않은 건 비워 둬."

보관함을 고치는 일은 되돌리기 어렵기 때문에, 백업을 두거나 깃으로 관리하는 보관함에서 하는 편이 안전합니다. 작업 전에 이 노트들을 다시 찾아 쓰려면 자매 스킬 [vault-recall](https://github.com/reedodev/vault-recall)을 함께 씁니다.

## 절차
1. **데이터를 만듭니다.** 보관함 폴더는 읽기만 하고, 결과는 보관함 바깥 폴더에 씁니다.
   ```bash
   node scripts/build-data.mjs "<보관함 폴더>" --site ./brain-site --title "내 지식 저장고"
   ```
   `brain-site` 폴더에 `index.html`, `ai-engine.js`, `data.js`, `models.js`, `three.min.js`, `config.js`, `CREDITS.md`가 함께 들어갑니다. 결과 JSON의 `notes`, `links`, `regions`를 보고 그룹이 원하는 대로 나뉘었는지 확인합니다.
2. **화면을 엽니다.** 브라우저가 `file://`로 연 파일의 스크립트를 막는 경우가 있으므로 내 컴퓨터 안에서만 열리는 작은 서버를 씁니다.
   ```bash
   node scripts/serve.mjs ./brain-site 8770
   ```
   그다음 브라우저에서 `http://127.0.0.1:8770/`을 엽니다. 이 서버는 127.0.0.1에만 열리기 때문에 같은 네트워크의 다른 기기에서는 접속할 수 없습니다. 다 보면 `Ctrl+C`로 끕니다.
3. **조작합니다.** 끌어서 돌리고 휠로 확대하며, 점을 누르면 그 노트가 왼쪽 아래 카드와 LINKED 칸에 고정됩니다. `B`·`T`·`A` 키나 위쪽 버튼으로 뇌·세계수·AI 엔진을 오가고(`A`를 한 번 더 누르면 바로 전 화면으로), 오른쪽 메뉴로 배경을 바꿀 수 있습니다. AI 엔진 탭에서는 끌어서 돌리고 도구를 누르면 그 도구 쪽으로 다가가며 관련 노트 목록이 나오고, 빈 곳을 누르거나 `Esc`를 누르면 전체 보기로 돌아옵니다.
4. **검수합니다.** 화면이 비어 있으면 개발자 도구 콘솔이나 `window.__errs`에서 오류를 확인합니다. 아래 칸의 노트 제목과 개수가 실제 보관함과 맞는지 몇 개만 대조해 봅니다.

예시 데이터로 먼저 보고 싶다면 저장소에 들어 있는 가상 노트 66개를 그대로 씁니다.
```bash
node scripts/build-data.mjs examples/sample-vault --site ./brain-site --title "Sample Vault"
node scripts/serve.mjs ./brain-site
```

## 옵션
| 옵션 | 하는 일 |
|---|---|
| `--group-by auto\|folder\|type\|tag` | 노트를 나누는 기준입니다. `auto`는 노트 절반 이상에 `type`이 있으면 그것을, 아니면 첫 단계 폴더를 쓰고, 폴더가 세 개보다 적으면 첫 태그를 씁니다 |
| `--title "이름"` | 화면 위쪽 제목입니다. 없으면 보관함 폴더 이름을 쓰고, 가림 옵션을 켜면 `Knowledge Brain`을 씁니다 |
| `--hide-titles` | 노트 제목을 `그룹 #번호`로 바꿉니다 |
| `--hide-groups` | 그룹 이름도 `Group A`부터 `Group F`로 바꿉니다 |
| `--exclude-hubs N\|auto` | 링크가 N개보다 많은 목차(MOC) 노트에 닿는 선은 그리지 않습니다. 통계에는 그대로 셉니다. `auto`는 전체 노트의 25%(최소 50)입니다 |
| `--max-edges N` | 화면에 그리는 선의 최대 개수입니다(기본 5,500) |
| `--ignore "Templates,Archive"` | 건너뛸 폴더 이름입니다. 점(.)으로 시작하는 폴더는 항상 건너뜁니다 |
| `--ok-status "verified,done"` | 확인된 노트로 보고 점을 크게 그릴 `status` 값입니다 |
| `--recent-days N`, `--chart-days N` | 최근으로 칠 날 수(기본 7)와 일별 그래프에 보일 날 수(기본 30)입니다 |
| `--out data.js` | 뷰어 파일 없이 `data.js` 하나만 씁니다 |

뇌의 여섯 영역은 가장 큰 그룹 다섯 개가 전두엽, 두정엽, 측두엽, 후두엽, 소뇌 순서로 들어가고 나머지 그룹은 모두 뇌줄기(세계수의 줄기)로 모입니다. 세계수 화면에서는 소뇌 그룹이 뿌리, 뇌줄기 그룹이 줄기, 나머지 네 그룹이 가지가 됩니다. 이 대응은 보기 좋게 정한 비유일 뿐이고 뇌 과학의 기능 구분과는 관계가 없습니다.

## 데이터를 읽는 방법
- 제목은 머리말(frontmatter)의 `title`이 있으면 그것을, 없으면 파일 이름을 씁니다.
- 만든 날은 `created`, `date`, 파일 이름 속 날짜, 파일 생성·수정 시각의 순서로 찾습니다. 깃으로 받은 폴더는 파일 시각이 받은 날로 바뀌기 때문에, 날짜 그래프를 정확히 보려면 머리말에 `created`를 넣어 두는 편이 좋습니다.
- 링크는 `[[노트 이름]]`, `[[노트|별칭]]`, `[[폴더/노트#제목]]`, `[글](노트.md)`를 파일 이름 기준으로 찾아 잇고, 코드 블록 안의 링크는 세지 않습니다. 대상 노트가 없는 링크는 `unresolvedLinks`로만 셉니다.

## 모양 바꾸기: 이렇게 말하세요
모양은 출력 폴더(예: `brain-site`)의 **`config.js`** 한 파일에서 바꿉니다. `index.html`을 고칠 필요가 없고, `build-data.mjs --site`로 다시 만들어도 이미 있는 `config.js`는 덮어쓰지 않습니다. 에이전트에게 아래 왼쪽처럼 말하면 오른쪽 값을 바꿉니다.

| 이렇게 말하면 | 바뀌는 곳 |
|---|---|
| "처음부터 세계수 화면으로 열리게 해 줘" | `config.js` → `startMode: 'tree'` |
| "배경을 우주로 바꿔 줘" / "배경 없애 줘" | `background: 'space'` / `'none'` (`net`, `hex`, `rain`, `contour`도 있음) |
| "해골 빼고 뇌만 보여 줘" | `hideSkull: true` |
| "더 천천히 돌게" / "돌지 않게" | `rotateSpeed: 0.04` / `0` |
| "빛 번짐 줄여 줘" / "더 화려하게" | `bloom: { strength: 0.3 }` / `{ strength: 1.2 }` |
| "영역 색을 따뜻한 색으로 바꿔 줘" | `colors: ['#ff8a3d', '#ffd166', '#ef476f', '#c77dff', '#06d6a0', '#ffffff']` (순서: 전두엽, 두정엽, 측두엽, 후두엽, 소뇌=뿌리, 뇌줄기=줄기) |
| "바탕을 진한 남색으로, 글자는 흰색으로" | `ui: { bg: '#0b1530', ink: '#ffffff' }` |
| "폴더 말고 태그로 나눠 줘" | 다시 빌드: `--group-by tag` |
| "목차 노트에 몰린 선 빼 줘" | 다시 빌드: `--exclude-hubs auto` |
| "제목을 '내 두 번째 뇌'로 해 줘" | 다시 빌드: `--title "내 두 번째 뇌"` |
| "공개용으로 제목 가려 줘" | 다시 빌드: `--hide-titles --hide-groups` |
| "처음부터 AI 엔진 탭으로 열리게" | `startMode: 'ai'` (주소로는 `?mode=ai`) |
| "AI 탭 이름을 '내 도구'로" | `aiTabName: '내 도구'` |
| "AI 탭 큰 제목을 바꿔 줘" | `aiTitle: '내 도구들이 한 뇌로'` |
| "AI 탭에 Cursor 넣어 줘" | `aiTools`에 한 줄 추가: `{ id: 'cursor', name: 'Cursor', sub: '코드 편집', color: '#7fd0ff', match: 'cursor\|커서' }` |
| "Notion 빼 줘" | `aiTools`에서 그 줄 삭제 |
| "'GPT'라고만 쓴 노트도 ChatGPT로 세 줘" | 그 도구의 `match`를 넓힘: `'chatgpt\|\\bgpt'` (대소문자 무시 정규식. 문자열 안이라 `\b`를 `\\b`로 씀) |
| "도구 아이콘 모양 바꿔 줘" | `icon: 'star'` 등 (`crystal`, `square`, `burst`, `orbit`, `star`, `branch`, `dots`, `hex`, `lens`, `eye`) |
| "AI 탭 없애 줘" | `aiTools: []` |

파일을 고치지 않고 잠깐 시험해 보려면 주소 뒤에 옵션을 붙입니다. 주소 옵션이 `config.js`보다 우선합니다.
```
http://127.0.0.1:8770/?mode=tree&bg=space&speed=0&skull=0&jaw=1
http://127.0.0.1:8770/?mode=ai
```

**AI 엔진 탭의 숫자에 대해**: 도구 칸의 숫자는 노트 **제목**에서 그 도구의 `match`가 걸린 노트 수이고, 본문은 보지 않습니다. 예시 숫자를 꾸며 넣지 않으므로 제목에 도구 이름을 잘 안 쓰는 보관함에서는 0이 많이 나올 수 있습니다. 이때는 `match`에 그 도구를 부르는 다른 이름(한글 이름, 줄임말)을 더합니다. 아래 흐름 기록(log)은 실제 작업 기록이 아니라 실제 노트 제목을 차례로 보여 주는 연출입니다. `aiTools` 줄을 통째로 지운 예전 `config.js`라면 기본 예시 도구(Obsidian, Notion, Claude, ChatGPT, Gemini, Git)를 씁니다. 도구는 12개까지 보입니다.

**모양을 바꾼 뒤에는** 브라우저를 새로고침하고 개발자 도구 콘솔에서 `window.__errs`가 빈 목록(`[]`)인지 확인한 뒤 화면을 직접 봅니다. 배경을 위쪽 메뉴로 고른 적이 있으면 그 선택이 브라우저에 저장돼 `config.js`보다 앞서므로, 주소에 `?bg=`를 붙이거나 메뉴에서 다시 고릅니다.

**더 큰 변경**(뇌 대신 다른 모양, 아래 여섯 칸 바꾸기)은 `config.js`로는 안 되고 `viewer/index.html`을 고쳐야 합니다. 이때는 에이전트에게 "원본은 두고 `index.html`을 복사해서 고쳐 줘, 바꾼 뒤 오류가 0개인지와 화면을 확인해 줘"처럼 백업과 확인까지 함께 요청합니다. 뇌·두개골 모델을 계속 쓴다면 오른쪽 아래 CC BY 출처 줄은 남겨 둡니다.

## 공개할 때 주의
- `--hide-titles`로 만든 화면의 AI 엔진 탭은 가려진 제목(`그룹 #번호`)만 보여 줍니다. 도구별 개수는 빌드할 때 실제 제목으로 세어 `data.js`의 `aiHits`(도구별 노트 번호 목록)에 넣으므로, 어떤 가린 노트가 어떤 도구와 관련 있는지는 드러납니다. 도구 이름 자체를 숨기고 싶다면 `aiTools: []`로 탭을 끕니다. `aiTools`를 고친 뒤에는 다시 빌드해야 가린 화면의 개수가 바뀝니다.
- `data.js`에는 노트 본문이 들어가지 않지만 **제목, 그룹 이름, 날짜, 상태는 그대로 들어갑니다.** 제목에 이름, 회사, 주소, 계정, 건강·돈 이야기가 섞여 있다면 공개하기 전에 `--hide-titles --hide-groups`를 켜거나 직접 확인한 제목만 남깁니다.
- 공개용으로 만든 `data.js`는 브라우저에서 누구나 내려받을 수 있습니다. 가렸다고 생각한 내용이 남아 있지 않은지 파일을 직접 열어 검색해 봅니다.
- 뇌와 두개골 모델은 CC BY 4.0이므로 화면 오른쪽 아래의 출처 줄을 지우지 않고, `CREDITS.md`를 함께 올립니다.
- 이 스킬은 보관함을 고치거나 노트를 새로 만들지 않습니다. 출력 폴더가 보관함 안이면 스크립트가 쓰기를 거부합니다.

## 한계
- 연결은 노트에 실제로 적힌 링크만 씁니다. 내용이 비슷한 노트를 AI로 이어 주는 기능은 없습니다.
- 3D 효과(빛 번짐, 단면 세 개)가 무거워서 그래픽 성능이 낮은 컴퓨터에서는 화면이 끊길 수 있습니다. 시험한 브라우저에서는 노트 60개와 8,000개 모두 초당 약 16프레임이었으므로 노트 수보다 그래픽 처리 쪽의 부담이 큽니다.
- 노트가 아주 많으면 선은 `--max-edges`만큼만 그립니다. 아래 칸의 그래프 값(|V|, |E|, 연결 성분 수)도 그려진 선 기준이므로 전체 링크 수는 오른쪽 아래 줄과 빌드 결과를 봅니다.
- 그룹이 여섯 개보다 많으면 작은 그룹들은 하나의 `other`로 합쳐집니다.
- 휴대폰처럼 좁은 화면에서는 아래 칸이 잘립니다. 넓은 화면을 기준으로 만들었습니다.
